# Milestone Scenario Catalog

## Document information

| Field | Value |
|---|---|
| Milestone | Name and number |
| Status | Draft for review |
| Owner | Name |
| Planned delivery | Pull request or release |
| Requirements | Links to test basis |

## Executive summary

Explain the feature, the main quality risk, and the purpose of this catalog in
plain English. State clearly that planned scenarios are not passed evidence.

## Situation

Describe the customer, merchant, operational, or technical situation that led to
this testing work.

## Business risks

| Risk | Possible impact | Priority |
|---|---|---|
| Describe the risk | Explain who may be affected and how | Critical, High, Medium, or Low |

## Scope

List what this milestone will test and what remains outside its boundary.

## Proposed decisions and assumptions

Explain important choices before implementation. Separate recommendations from
approved requirements. Include alternatives when the trade-off matters.
